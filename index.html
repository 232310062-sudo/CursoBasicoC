Variables: cajas con nombre

Una variable es una caja en la memoria. Tiene un tipo (qué guarda), un nombre y un valor.







Prueba: pon int con el valor 3.5, o bool con true.








if / else: tomar decisiones


El programa evalúa una condición. Si es verdadera entra por un camino; si no, por el otro.



int edad = 18;
if (edad >= 18)
{
    Console.WriteLine("Puedes entrar");
}
else
{
    Console.WriteLine("Aún no puedes entrar");
}






if (verdadero)
Puedes entrar


else (falso)
Aún no puedes entrar










for: repetir sin copiar y pegar


Un bucle repite un bloque de código. Aquí i cambia en cada vuelta.








for (int i = 1; i <= 5; i++)
{
    Console.WriteLine(i);
}
